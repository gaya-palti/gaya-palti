## VinyasaVision

**[Web app](https://vinyasa-vision.web.app)** · **[Demo](https://drive.google.com/file/d/1pIMUbc9Qz2r6oLaa8tOv3InJoSf2uXhf/view)**

A yoga teacher films her practice, and VinyasaVision turns the video into an editable class plan with an ordered list of poses and their timings, ready to rearrange on her phone and export as a PDF. MediaPipe tracks the teacher's body, a classifier trained on joint angles recognises 146 poses, and Viterbi smoothing turns frame-by-frame guesses into clean pose cards.

**Stack:** Flutter, Firebase, Python, MediaPipe, scikit-learn, Oracle Cloud

## OSINT Analyzer

**[Repo](https://github.com/gaya-palti/OSINT-analyzer)** · **[Demo](https://drive.google.com/file/d/1AyMDZNaXBFP7r40-LWz9HS6gMKHW1FCb/view)**

A chain of vision LLMs analyses satellite imagery. Given a coordinate, it pilots Google Earth with a headless browser, an analyst model decides where to zoom and pan next, and a second model combines the analyst's notes into one report, all shown in a Streamlit dashboard.

**Stack:** Selenium, OpenAI, Gemini, Moondream, Streamlit

## Generation 2048

**[Repo](https://github.com/gaya-palti/2048-Neural-Network)** · **[Demo](https://drive.google.com/file/d/10Ub3lf5qAm_pCEzkI1rbRr9l9-bLw759/view)**

A neural network that learns 2048 through neuroevolution, with no labelled data and no gradient descent. The best agent is a 1,281-weight network evolved by a genetic algorithm; it reaches the 2048 tile in 29% of games and 1024 in 79%.

**Stack:** Keras, NumPy, FastAPI, React, Pygame

## Iceberg-Style Columnar Database Engine

**[Repo](https://github.com/gaya-palti/Iceberg-Style-Columnar-Database-Engine)**

A columnar database engine inspired by Apache Iceberg, from on-disk storage up to queries: a binary column-major file format, a metadata catalog with per-file statistics, Volcano-style query operators, and an optimizer that re-clusters data based on the query workload.
